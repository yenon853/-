# רילס: כיתה הפוכה – לומדים קשרים לוגיים

פרויקט עריכה שמבנה מחדש את הרילס מהסרטון המקורי. כל השינויים נעשים בקבצים בתיקייה הזו, ואז מריצים את הסקריפט מחדש.

## מה עורכים ואיפה

| מה רוצים לשנות | איפה |
|---|---|
| חיתוכים, סדר הקטעים, זומים | `SEGMENTS` בראש `build_reel.py` |
| חלוקת הכתוביות לשורות | `CAPTION_LINES` ב-`build_reel.py` |
| מילים מודגשות וצבעים | `HIGHLIGHT` וקבועי הצבע `NAVY / TURQ / YELL` |
| תיקון מילה בתמלול | `transcript_words.json` (וגם השורה המתאימה ב-`CAPTION_LINES`) |
| גרפיקה ואנימציות | הפונקציה `graphics()` |
| תיקון צבע | `DECODE_VF` (בהירות, ניגודיות, איזון לבן) |
| קול ומוזיקה | `render_audio()` (ניקוי רעשים, דחיסה, ‎-14 LUFS, עוצמת מוזיקה) |

אפשר לפתוח את `output/reel_overlays.ass` גם ב-Aegisub ולערוך בו כתוביות וגרפיקה ידנית.

## הרצה

```bash
python3 build_reel.py /path/to/original.mp4
```

דגלים: `--subs-only` מייצר רק כתוביות ו-ASS, `--cover-only` מייצר רק את הקאבר, ו-`--audio-only` מייצר מחדש רק את הסאונד ומחבר אותו לווידאו הקיים.

נדרשים: ffmpeg (עם libass ו-libx264), ו-Python עם numpy, ‏`opencv-python-headless<5` ו-pillow. הגופן הוא Heebo (רישיון OFL) ונמצא ב-`fonts/`.

קובצי הווידאו והקאבר (`output/*.mp4`, ‏`output/cover.jpg`) לא נשמרים בריפו כי הוא ציבורי.

## גרסה 2: אולפן וירטואלי ועריכה דינמית (`v2/`)

| שלב | קובץ | מה הוא עושה |
|---|---|---|
| 1 | `v2/matte.py` | הפרדת הדמות מהרקע בכל פריים בעזרת מודל ISNet (ONNX). התוצאה נשמרת כמסכות PNG. |
| 2 | `v2/studio.py` | אולפן וירטואלי שנבנה בקוד: קירות כחול כהה, פסי LED טורקיז, אור חם, ספריות, מסך דיגיטלי ובוקה. |
| 3 | `v2/build_v2.py` | תנועת המצלמה, הרכבת השכבות, הכתוביות, הגרפיקה, אפקטי הסאונד, המוזיקה והקאבר. |

```bash
python3 v2/matte.py /path/to/original.mp4 /path/to/isnet.onnx /path/to/matte_cache
python3 v2/build_v2.py /path/to/original.mp4 /path/to/matte_cache
```

מה עורכים ב-`build_v2.py`:
- `CAM`: הזומים, ה-punch, ה-zoom out וההזזה הצידה למסך מפוצל, בכל קטע.
- `TRANS`: סוג המעבר בין קטעים (whip pan, zoom blur, חיתוך).
- `SCREEN_TL`: מה מוצג על המסך שמאחוריך ומתי.
- `graphics()`: כל הגרפיקה. כל אנימציה מסמנת את מילת הקישור שנאמרת באותו רגע: ניגוד ("אלא"), סיבה ותוצאה ("כדי ש..."), הוספה, ורצף.
- `make_music()` ו-`make_sfx()`: המוזיקה והאפקטים. שניהם נוצרים בקוד ולכן אין צורך ברישיון.

מודל ההפרדה הוא ISNet מתוך החבילה `@imgly/background-removal-node` (רישיון AGPL). הוא משמש כאן ככלי עיבוד בלבד ולא מופץ בריפו.

התוצרים נשמרים ב-`output_v2/`, והווידאו והקאבר לא נכנסים ל-git.

## גרסה 3: האולפן מהתמונה, מסך חכם ותוצרים מלאים (`v3/`)

```bash
python3 v3/build_v3.py /path/to/original.mp4 /path/to/matte_cache /path/to/studio_image.webp
```

מה השתנה לעומת גרסה 2:
- **הרקע:** האולפן נבנה מהתמונה שסיפקת (`v3/studio_image.py`). התמונה הוגדלה פי 2 וחותכה לאנכי, והמסך הגדול שבה הוחלף בתוכן השיעור.
- **מסך חכם:** התוכן על המסך מתחלף לפי הדיבור ("למה", בבית ← בכיתה, למידה עצמאית, מפת קשרים לוגיים, כיתה הפוכה), ופס אור עובר עליו.
- **פלטת צבעים:** ‎#101B35, ‏#00D9E8, ‏#FFD447, ‏#65AFFF.
- **מעברים:** נוסף wipe גרפי, וחלקיקים במעברי whip pan.
- **סאונד:** נוספו Rise לפני רגעי שיא ו-Soft Impact על כותרות.
- **כתוביות:** מושגים לימודיים בטורקיז, מילים משמעותיות בצהוב, וקו תחתון מונפש מתחת לכותרות.

התוצרים נשמרים ב-`output_v3/`: רילס עם כתוביות, רילס בלי כתוביות, SRT, ‏ASS, קאבר, ‏`EDL_v3.md` ו-`sfx_cues.json`. התיאור לפרסום נמצא ב-`v3/description.md`.

## גרסה 4: פרימיום (`v4/`)

```bash
python3 v4/sr_onnx.py <@plotdb/upscaler>/models/realesrgan/general_fast-64 realesr_general_x4v3.onnx
python3 v4/sr_cache.py /path/to/original.mp4 realesr_general_x4v3.onnx /path/to/sr_cache
python3 v4/build_v4.py /path/to/original.mp4 /path/to/matte_cache /path/to/studio_image.webp /path/to/sr_cache
```

| מודול | מה הוא עושה |
|---|---|
| `v4/sr_onnx.py` | בונה מחדש את Real-ESRGAN general-x4v3 (SRVGGNetCompact) מקובץ TensorFlow.js, כמודל ONNX שרץ על CPU |
| `v4/sr_cache.py` | מחדד פרטים בפנים, בשיער ובעיניים בכל פריים, באזור שעוקב אחרי הפנים |
| `v4/layers.py` | אולפן 2.5D מהתמונה: קיר ומסך, דסק, רצפה ותקרה, כל אחד בעומק אחר, עם קרני אור מהנורות |
| `v4/hero.py` | מילות ענק בתלת-ממד שמוצבות מאחוריך, בין האולפן לבינך |
| `v4/captions_v4.py` | כתוביות word-box: כל מילה נדלקת כשהיא נאמרת, ותיבה קופצת ממילה למילה |
| `v4/finish.py` | גרייד split-tone, ‏bloom, גרעין פילם, סטייה כרומטית ו-light leaks |
| `v4/build_v4.py` | המצלמה הווירטואלית, ההרכבה, הגרפיקה כשכבה זוהרת, הפסקול והאפקטים, הקאבר, ה-EDL ובדיקת אזורים בטוחים |

**נתונים טכניים:**
- **חידוד:** משקל המודל 55% ומשקל המקור 45%, כדי לשמור על מרקם עור טבעי.
- **מצלמה:** רעידת יד של ±5px ו-±0.2°, ובפתיחה גלגול מצלמה של 3.2°.
- **פרלקסה:** קיר 0.25, דסק 0.45, תקרה 0.55, רצפה 0.60, מילות ענק 0.35, ואתה 1.0.

התוצרים נשמרים ב-`output_v4/`: ‏`reel_kita_hafucha_v4.mp4`, גרסה בלי כתוביות, ‏`cover_v4.jpg`, ‏`reel_v4.srt`, קובצי ASS (גרפיקה, כתוביות וקובץ מלא), ‏`EDL_v4.md`, ‏`safe_zones_check.jpg` ו-`sfx_cues.json`.

הקוד של מודל ה-ONNX לא נשמר בריפו. משקלי Real-ESRGAN הם ברישיון BSD-3, ו-ISNet ברישיון AGPL. שניהם משמשים ככלי עיבוד בלבד.
