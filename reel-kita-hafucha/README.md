# רילס: כיתה הפוכה – לומדים קשרים לוגיים

פרויקט עריכה שמבנה מחדש את הרילס מהסרטון המקורי. כל השינויים נעשים בקבצים בתיקייה הזו, ואז מריצים את הסקריפט מחדש.

## מה עורכים ואיפה

| מה רוצים לשנות | איפה |
|---|---|
| חיתוכים, סדר הקטעים, זומים | `SEGMENTS` בראש `build_reel.py` |
| חלוקת הכתוביות לשורות | `CAPTION_LINES` ב-`build_reel.py` |
| מילים מודגשות וצבעים | `HIGHLIGHT` וקבועי הצבע `NAVY / TURQ / YELL` |
| תיקון מילה בתמלול | `transcript_words.json` (וגם השורה המתאימה ב-`CAPTION_LINES`) |
| גרפיקה ואנימציות | הפונקציה `graphics()` |
| תיקון צבע | `DECODE_VF` (בהירות, ניגודיות, איזון לבן) |
| קול ומוזיקה | `render_audio()` (ניקוי רעשים, דחיסה, ‎-14 LUFS, עוצמת מוזיקה) |

אפשר לפתוח את `output/reel_overlays.ass` גם ב-Aegisub ולערוך בו כתוביות וגרפיקה ידנית.

## הרצה

```bash
python3 build_reel.py /path/to/original.mp4
```

דגלים: `--subs-only` מייצר רק כתוביות ו-ASS, `--cover-only` מייצר רק את הקאבר, ו-`--audio-only` מייצר מחדש רק את הסאונד ומחבר אותו לווידאו הקיים.

נדרשים: ffmpeg (עם libass ו-libx264), ו-Python עם numpy, ‏`opencv-python-headless<5` ו-pillow. הגופן הוא Heebo (רישיון OFL) ונמצא ב-`fonts/`.

קובצי הווידאו והקאבר (`output/*.mp4`, ‏`output/cover.jpg`) לא נשמרים בריפו כי הוא ציבורי.
