# אתר ינון זנו — בינה אנושית. יתרון טכנולוגי.

אתר תדמית אישי (עמוד נחיתה) של **ינון זנו**, מדריך תקשוב מחוז מרכז.
נבנה מתוך העיצוב שיוצא מ-Claude Design (`Yinon Zano Mobile.dc.html` / `Yinon Zano Website.dc.html`),
ומומש כאתר סטטי אמיתי, רספונסיבי ומלא — עובד גם במובייל וגם בדסקטופ.

## מבנה

- `index.html` — עמוד הבית (RTL, עברית). כל ה-CSS מוטמע בקובץ.
- `services/` — עמוד לכל אחד מחמשת השירותים (שיחה אישית ממוקדת, סדנאות מעשיות לצוותי חינוך, ליווי בית־ספרי, פיתוח כלים לימודיים מותאמים, פיתוח אתרים לעולם החינוך).
- `projects.html` — פרויקטים ותוצאות.
- `blog/` — הבלוג ושלושת המאמרים.
- `assets/` — לוגו, תמונת הרקע של ה-hero, favicon ואייקוני Phosphor (מאוחסנים מקומית).
- `deploy/standalone.html` — גרסה של עמוד הבית עם כל הנכסים מוטמעים (נבנית בסקריפט).
- `llms.txt`, `sitemap.xml`, `robots.txt` — קבצי גילוי לזחלנים ולמנועי AI.

הכותרת העליונה והתחתונה (header/footer) זהות בכל העמודים ומכילות את חמשת השירותים באותו סדר.

## טכנולוגיה

- HTML + CSS סטטי, ללא תלות בבנייה (build).
- טיפוגרפיה: Suez One (כותרות) + Varela Round (גוף) מ-Google Fonts.
- אייקונים: Phosphor Icons (duotone), מאוחסנים מקומית ב-`assets/phosphor/`.
- מבוסס על מערכת העיצוב `yinon-zano-design-system` (צבעי לילה־כחול, טוקנים של צבע/טיפוגרפיה/מרווחים).

## הרצה מקומית

פתיחת `index.html` בדפדפן, או:

```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```
