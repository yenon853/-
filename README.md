# אתר ינון זנו — בינה אנושית. יתרון טכנולוגי.

אתר תדמית אישי (עמוד נחיתה) של **ינון זנו**, מדריך תקשוב מחוז מרכז.
נבנה מתוך העיצוב שיוצא מ-Claude Design (`Yinon Zano Mobile.dc.html` / `Yinon Zano Website.dc.html`),
ומומש כאתר סטטי אמיתי, רספונסיבי ומלא — עובד גם במובייל וגם בדסקטופ.

## מבנה

- `index.html` — האתר המלא (RTL, עברית). כל ה-CSS מוטמע בקובץ.
- `assets/` — לוגו (logo-mark.png, logo-wordmark.png).

## טכנולוגיה

- HTML + CSS סטטי, ללא תלות בבנייה (build).
- טיפוגרפיה: Suez One (כותרות) + Varela Round (גוף) מ-Google Fonts.
- אייקונים: Phosphor Icons (duotone) מ-CDN.
- מבוסס על מערכת העיצוב `yinon-zano-design-system` (צבעי לילה־כחול, טוקנים של צבע/טיפוגרפיה/מרווחים).

## הרצה מקומית

פתיחת `index.html` בדפדפן, או:

```bash
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```
