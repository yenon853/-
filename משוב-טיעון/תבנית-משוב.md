# תבנית פלט — משוב לתלמיד

לכל תלמיד מפיקים **שני חלקים**: גרסה להדבקה בקלאסרום, ונתונים למורה בלבד.

---

## 1. גרסה לקלאסרום (תגובה פרטית לתלמיד)

טקסט רגיל בלבד: בלי Markdown, בלי טבלאות, בלי `**`. תגובות בקלאסרום לא מציגות עיצוב.
עד כ-1,200 תווים. פנייה ישירה ונייטרלית מגדרית (ראו CLAUDE.md).

```
שלום [שם פרטי],

מה עובד במאמר: [עוגן — דבר אחד ספציפי, עם ציטוט קצר מהעבודה]

הצעד הבא שלך: [קידום — דבר אחד או שניים לכל היותר, מעשי ומדויק: איפה בדיוק ומה לעשות]

שאלה לחשוב עליה: [שאלה אמיתית על בחירה שנעשתה בעבודה]

תיקון לשון אחד: "[ציטוט מהעבודה]" ← "[נוסח מתוקן]" ([הסבר במילים ספורות])

[ציון: XX/100 — רק אם המורה ביקש לנקד]
```

## 2. נתונים למורה בלבד (לא נשלח לתלמיד)

```

| קריטריון | נק' | הערה קצרה |
| 1 טענה ומבנה | /20 | |

| 3 טענת נגד והפרכה | /15 | |

```

## 3. סיכום כיתתי (בסוף כל קבוצת עבודות)

```
כיתה [X] | [מספר] עבודות נבדקו | ממוצע: [XX] (אם נוקד)

3 חוזקות נפוצות: ...
3 פערים נפוצים: ... (כמה תלמידים, ודוגמה אנונימית)
הצעה לשיעור המשך (10–15 דק'): [מיקרו-שיעור ממוקד בפער המרכזי]
תלמידים שכדאי לפגוש אישית: [שמות + סיבה במשפט]
```

## דוגמה (תלמיד בדוי)

**לקלאסרום:**

```
שלום נועם,

מה עובד במאמר: הנימוק השני שלך חזק במיוחד: "מי שמקבל תשובה מוכנה מצ'אטבוט מדלג בדיוק על השלב שבו המוח מתאמץ ולומד". זה נימוק אמיתי ולא חזרה על הטענה, והוא מחובר היטב לנושא.

הצעד הבא שלך: בטענת הנגד כתבת "יש אנשים שחושבים ש-AI זה טוב". זו גרסה חלשה של הצד השני. כדאי לנסח את הטיעון הכי חזק שלו, למשל ש-AI מאפשר לתלמיד מתקשה לקבל הסבר מותאם אישית בכל שעה. אחר כך כדאי להפריך דווקא את הגרסה החזקה הזו, ולפתוח ב"אומנם... אך...".

שאלה לחשוב עליה: באיזה רגע בעבודה ה-AI כמעט שכנע אותך שטעית, ומה החזיר אותך לעמדה שלך?

תיקון לשון אחד: "הסיבה היא בגלל ש..." ← "הסיבה היא ש..." (במשפט המקורי הסיבה נאמרת פעמיים)
```

**למורה:** טענה ומבנה 16/20 · נימוקים 20/25 · נגד והפרכה 9/15 · קול אישי 17/20 · לשון 8/10 · רפלקציה: לא הוגש. חסר: קישור למקור בנימוק 3.
