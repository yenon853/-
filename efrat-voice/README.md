# תשאלו את אפרת! 🔍 – גרסה קולית

תרגול מודל אפר״ת (אירוע, פרשנות, רגש, תגובה) לתלמידי בית הספר "כנפי אבירים", עם שיחה קולית אמיתית בעברית.
הילד מדבר, אפרת או סבא חכם מקשיבים ועונים בקול, וכרטיסיית האפר״ת מתמלאת תוך כדי.

## איך הקול עובד

| חלק | ספק ראשי | גיבוי אוטומטי |
|---|---|---|
| זיהוי דיבור בעברית | Azure AI Speech, דרך השרת | זיהוי הדיבור של Chrome |
| הקראה בעברית | Azure: הקול "הילה" לאפרת והקול "אברי" לסבא חכם | הקול העברי של המכשיר, אם קיים |
| מוח השיחה | Gemini, דרך השרת | תשובות מוכנות לפי שלבי אפר״ת |

**מצב "שיחה קולית"**: הדמות מקריאה את השאלה ומקשיבה. היא מזהה לבד שהילד סיים לדבר, שולחת, ועונה בקול. אין צורך להקליד.

**מצב רגיל**: לוחצים על המיקרופון או על הדמות ומדברים. הטקסט נכנס לתיבה, ואפשר לבדוק אותו לפני השליחה.

## הפעלה מהירה

צריך Node.js בגרסה 22 ומעלה.

```bash
cd efrat-voice
npm install
cp .env.example .env      # ממלאים את המפתחות בקובץ .env
npm run dev               # פותחים http://localhost:5173
```

לשימוש בכיתה, שרת אחד מגיש את כל האתר:

```bash
npm run build
npm start                 # http://localhost:8787
```

## השגת המפתחות

**קול עברי – Azure AI Speech**
1. נכנסים ל-portal.azure.com ויוצרים משאב מסוג **Speech**.
2. בוחרים אזור, למשל West Europe, ותוכנית **Free F0** לפיילוט.
3. בעמוד **Keys and Endpoint** מעתיקים את KEY 1 ואת ה-Location.
4. ממלאים בקובץ `.env` את `AZURE_SPEECH_KEY` ואת `AZURE_SPEECH_REGION`, למשל `westeurope`.

**מוח השיחה – Gemini**
1. נכנסים ל-aistudio.google.com/apikey ויוצרים מפתח.
2. ממלאים את `GEMINI_API_KEY`. אם המודל שמופיע ב-`GEMINI_MODEL` הוצא משימוש, מחליפים אותו בשם של מודל עדכני.

גם בלי מפתחות האפליקציה עובדת. התשובות מגיעות מהגיבוי, והקול מגיע מהדפדפן.
בחלון **"מבט צוות"** רואים בדיוק מה מחובר כרגע.

## חשוב לפני שימוש עם תלמידים

- **המיקרופון דורש https.** כדי להשתמש בטאבלטים בכיתה צריך להעלות את האתר לכתובת מאובטחת. `localhost` עובד רק במחשב שמריץ את השרת.
- **פרטיות.** ההקלטה נשלחת ל-Azure לתמלול, וטקסט השיחה נשלח ל-Google כדי לנסח תשובה. השרת לא שומר הקלטות או שיחות. יומן הפיילוט נשמר רק בדפדפן של המכשיר, ואין בו את תוכן השיחה. מומלץ לאשר את השימוש מול הנחיות הפרטיות של משרד החינוך ומול הנהלת בית הספר.
- **מוגנות.** מילים כמו "הרביץ לי" או "לפגוע בעצמי" פותחות מיד חלון פנייה למבוגר. השיחה הקולית נעצרת, ובחלון מוצגים מוקד 105, ער״ן 1201 ומשטרה 100. הבדיקה רצה גם בדפדפן וגם בשרת, וממשיכה לפעול גם כשמודל השפה לא זמין. אפשר להרחיב את רשימת המילים ב-`shared/safety.js`.

## מה השתפר לעומת הגרסה המקורית

- **קול אמיתי במקום הדמיה.** ההקלטה המדומה הוסרה. כשאין מיקרופון מוצגת הודעה ברורה בעברית.
- **מפתחות מוגנים.** המפתחות שמורים בשרת, ולא בקוד שהדפדפן רואה.
- **פנייה במגדר הנכון.** בוחרים "ילד", "ילדה" או "לא משנה", והדמות מדברת בהתאם. אין לוכסנים שנשמעים רע בהקראה.
- **רגשות מזוהים מהדיבור.** משפט כמו "הייתי עצוב ונעלבתי" מסמן אוטומטית עצב ועלבון בכרטיסייה. נוספו הרגש "פחד" ומחוון עוצמה.
- **התקדמות מבוקרת.** המודל לא יכול לדלג על שלבים. שלב הפרשנות נמשך עד שעולה גם פרשנות נוספת.
- **יומן פיילוט אמיתי.** "שמירת תצפית" שומרת ביומן, ואפשר לייצא אותו לאקסל.
- **כרטיסיית סיכום** עם הקראה והדפסה.
- **תיקונים.** אות ערבית שהשתרבבה לטקסט ("يتמלא"), גלילה שדילגה על הדמות בטלפון, ועוד.

## מבנה הקבצים

```
efrat-voice/
├── server/            שרת Node: Gemini, הקראה וזיהוי דיבור של Azure
├── shared/            מוגנות וניקוי טקסט להקראה (משותף לשרת ולדפדפן)
└── src/
    ├── App.jsx        המסך הראשי ולולאת השיחה
    ├── characters.jsx אפרת וסבא חכם
    ├── efratConfig.js שלבים, רגשות, ברכות פתיחה
    ├── fallback.js    תשובות גיבוי
    ├── voice/         הקלטה, זיהוי סוף דיבור והקראה
    └── components/    חלונות: מבוגר, סיכום, מבט צוות
```
